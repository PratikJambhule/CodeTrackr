## The pipeline

```
raw session counts ──► backend/services/workTypeFeatures.js ──► 18 features
                                     │
               ┌─────────────────────┴───────────────────────┐
     backend/services/workType.js                  ml/train_work_type.py
     rules v1 (the baseline)               logistic regression vs depth-4 tree,
                                           GroupKFold by person, ship gate
                                                         │
                                           backend/ml/workTypeModel.json
                                                         │
                                       backend/services/workTypeModel.js
                                       (JavaScript prediction, parity-tested)
```

| File | What it does |
|---|---|
| `generate_synthetic.js` | seeded generator: 60 simulated people with their own habits → ~2,000 sessions as raw counts and real-looking commands; features computed by the production code |
| `train_work_type.py` | trains, evaluates on people never seen, compares with the rules, applies the ship gate, writes the model, parity fixtures and a report |
| `reports/` | one report per training run (kept, including runs that fail the gate) |
| `data/` | generated files (git-ignored; rebuild with the generator) |

## The ship gate (ML plan §11)

Measured on **blind** labels (the person was asked without seeing a guess) from people the model
never saw: macro-F1 at least 0.05 above the rules, and no work type's recall more than 0.05 below the
rules'. If it fails, the rules stay.
